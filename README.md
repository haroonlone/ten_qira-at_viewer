### Interactive Comparative Viewer for the Ten Qira’at Mushafs

## 📖 About the Project

This project provides an interactive comparative digital viewer for the Mushafs of the Ten Qira’at (القراءات العشر).

The original PDF files were obtained from:

Masahif at-Tayseer  
https://www.alwa7y.com/downloads/

The PDF files were converted into high-resolution images to enable precise side-by-side comparison and detailed zoom functionality.

---

## 🌟 Key Features

### 📚 Comparative View of 15 Mushafs
- Simultaneous display for comparison
- Clear visual alignment across Riwayat
- Designed for advanced Qira’at study

### 🔍 Zoom to Specific Riwayah
- Dedicated zoom view for focused reading
- Smooth navigation within each Mushaf

### ⌨ Navigation Options
- Keyboard navigation (Arrow keys)
- On-screen navigation arrows
- Surah selection
- Juz selection
- Direct page synchronization between zoom and main comparative view

---

This project is primarily designed for:

- Advanced readers studying Riwayat differences
